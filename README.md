# 🧠 Cognicare NER

### AI-Based Cognitive Gaming and Memory Assistance Platform for Elderly Dementia Patients in North Eastern Region (NER)

Cognicare NER is a personalized cognitive assistance platform designed to support elderly users through engaging memory activities, personalized cognitive games, memory assistance, reminders, and caregiver support.

## 🚀 Key Features

- 🧠 Personalized Cognitive Games
- 🧩 Memory Match
- 🔢 Sequence Memory
- 🖼️ Object Recall
- 🗣️ Voice Interaction
- 📸 Personal Memories
- ⏰ Reminders
- 👨‍👩‍👧 Caregiver Support
- 📊 Personalized activity recommendations
- 🌐 Elder-friendly interface
- 📱 Progressive Web App (PWA)

## 🎯 Problem We Address

Elderly people experiencing memory-related difficulties can benefit from regular cognitive stimulation and simple, accessible digital assistance.

Cognicare NER aims to provide an easy-to-use platform that combines cognitive activities with personalized assistance while keeping the experience simple and elder-friendly.

## 💡 Our Solution

Cognicare NER combines:

- Cognitive games
- Memory assistance
- Personalized recommendations
- Voice interaction
- Caregiver-oriented features

The platform observes activity such as accuracy, response time, and mistakes to personalize subsequent activities.

🌟 Innovation
Cognicare NER focuses on personalization and accessibility rather than treating cognitive assistance as a one-size-fits-all experience.
The platform can adapt activities according to the user's interaction and performance, while providing an interface designed with elderly users in mind.
🔐 Privacy

The project is designed with user-data privacy in mind. Personal information, sessions, memories, and activity-related data are handled through the application's backend and database.
