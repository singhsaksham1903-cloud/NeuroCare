8. Duplicate check in PostgreSQL (recommended)
   SELECT client_session_id, COUNT(*)
   FROM game_sessions
   WHERE client_session_id IS NOT NULL
   GROUP BY client_session_id
   HAVING COUNT(*) > 1;

   SELECT client_mutation_id, COUNT(*)
   FROM memories
   WHERE client_mutation_id IS NOT NULL
   GROUP BY client_mutation_id
   HAVING COUNT(*) > 1;

   SELECT client_mutation_id, COUNT(*)
   FROM reminders
   WHERE client_mutation_id IS NOT NULL
   GROUP BY client_mutation_id
   HAVING COUNT(*) > 1;

   All three queries should return 0 rows.

9. Important limitation for SIH demo
   Offline changes are stored in the browser's local storage until synchronization. If the site data is manually cleared before reconnecting, those unsynced local changes are lost. This prototype does not implement encrypted offline storage or background push synchronization while the app is completely closed.
